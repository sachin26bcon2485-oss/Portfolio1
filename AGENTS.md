## Portfolio architecture
- Keep the portfolio in the index route with in-page anchor navigation because the requested experience is a single smooth-scrolling page.
- Define reusable portfolio styling and semantic tokens in the global stylesheet because all sections share one visual system.
- Keep missing personal links and message delivery explicitly unavailable until real destinations are provided because invented links and false submission confirmations are misleading.
